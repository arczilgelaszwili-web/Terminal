# Terminal iPhone-ისთვის (კომპიუტერის გარეშე)

ეს არის იგივე აპი, ოღონდ ისე შეფუთული, რომ პირდაპირ iPhone-იდან აიტვირთოს. მთელი აპი ერთ ფაილშია (`index.html`),
დანარჩენი სამი მხოლოდ დამხმარეა. **ყველა ფაილი ერთად, ერთ საქაღალდეში უნდა აიტვირთოს.**

## დაყენება GitHub Pages-ზე (უფასოა)

1. Files აპში დააჭირე ამ ZIP-ს, რომ გაიხსნას. გაჩნდება საქაღალდე `terminal-iphone`.
2. Safari-ში გახსენი github.com და შექმენი ანგარიში (ან შედი, თუ გაქვს).
3. გახსენი github.com/new. **Repository name**: `terminal`. აირჩიე **Public**. სხვა არაფერი მონიშნო
   (README-ს არ დაამატო). დააჭირე **Create repository**.
4. გვერდზე იქნება ბმული **uploading an existing file**. დააჭირე მას.
5. დააჭირე **choose your files** → **Choose Files** → გახსენი საქაღალდე `terminal-iphone` →
   **Select** (მარჯვნივ ზემოთ) → მონიშნე ყველა ფაილი → **Open**.
6. გადაახვიე ქვემოთ და დააჭირე **Commit changes**.
7. გახსენი `github.com/შენი-სახელი/terminal/settings/pages`. იქ **Source**: Deploy from a branch;
   **Branch**: `main` და `/ (root)`; დააჭირე **Save**.
8. დაელოდე 1–2 წუთს და განაახლე გვერდი. ზემოთ გამოჩნდება მისამართი, მაგალითად `https://შენი-სახელი.github.io/terminal/`.
9. გახსენი ეს მისამართი Safari-ში. პირველად გვერდი თავისით ერთხელ გადაიტვირთება, ეს ნორმალურია.
   შემდეგ: გაზიარება (კვადრატი ისრით) → **მთავარ ეკრანზე დამატება**.
10. აპი მუდამ ხატულიდან გახსენი, არა Safari-დან. ფაილები ინახება ხატულის აპის შიგნით, Safari-ში ცალკეა.
    პირველი ჩატვირთვა რამდენიმე წუთს გრძელდება, რადგან Linux-ის დისკი ნაწილ-ნაწილ იტვირთება.

## თუ არ ირთვება

მენიუდან (⋮) ან შეცდომის ეკრანიდან აირჩიე **დიაგნოსტიკა → კოპირება** და გამომიგზავნე ტექსტი.
აპის გამოყენება, შეზღუდვები და ლიცენზია იგივეა, რაც მთავარი ZIP-ის `README.md`-ში წერია.

ახალი ვერსიის დასაყენებლად საცავში (repository) ისევ ატვირთე ფაილები: **Add file → Upload files**. იგივე სახელის ფაილები ჩაანაცვლდება.
